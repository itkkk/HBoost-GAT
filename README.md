Code for **HBoost-GAT** (Heterogeneous Boosted GAT), a multi-view boosting framework based on heterogeneous Graph Attention Networks for cancer diagnosis from extracellular miRNA expression profiles.

> A. Pellicani, G. Detomaso, E. Tavoletti, G. Pio, M. Ceci. *Boosting Heterogeneous Graph Attention Networks for Cancer Diagnosis from Extracellular microRNA Expression Data.* Submitted to Bioinformatics, 2026.

## Method overview

**Heterogeneous graph.** Patients and miRNAs are two node types:
- **Patient nodes**: miRNA expression profiles, reduced with PCA.
- **miRNA nodes**: 120-dimensional sequence embeddings from [RNABert](https://github.com/mana438/RNABERT), averaged over the sequence tokens.

There are three edge types:
- **patient ↔ miRNA**: one edge for every available expression value, weighted by that value.
- **patient ↔ patient**: patient's nearest neighbours in the PCA space, found with an approximate nearest-neighbour search ([Annoy](https://github.com/spotify/annoy)) and weighted by similarity.
- **miRNA ↔ miRNA**: miRNA's nearest neighbours in the RNABert embedding space.

**Multi-view boosting.** The expression data is projected with PCA at several levels of compression, for example 128/256/512 or 64/128/256/512/1024 components. Each level gives a different graph (view): patient features and patient-patient edges change between views, while the rest of the graph stays the same. The views are combined with an extension of **irBoost.SH**, a multi-view boosting algorithm based on adversarial multi-armed bandits. At each of the T iterations it:
1. Picks a winning view by bandit sampling (exploration σ = 0.15, γ = 0.3).
2. Trains a GAT on that view's graph using a focal loss (λ = 1) weighted by the shared instance weights. Instance weights start at log inverse class frequency.
3. Updates the view probabilities and the instance weights.

The final prediction is the α-weighted sum of the softmax outputs of all T learners.

## Dataset

The data comes from **[ExomiRHub](https://doi.org/10.1016/j.csbj.2024.07.024)**: 191 GEO studies with 29,198 samples. `mir_gatboost/dataset.py` filters and harmonizes the studies into a single dataset, as described in Sec. 2.1 of the paper. It uses these files in `data/external/`:

- `disease_labels.json` and `sample_type_labels.json`: per-study rules that map metadata to disease labels and sample types.
- `miRNA.tsv`: maps miRNA names to miRBase v22.

The microarray subset used in the paper has 25,627 samples: 17 tumor types plus healthy controls. The preprocessed dataset is also available on [Hugging Face](https://huggingface.co/datasets/ant-p/cancer-mirna-18).

## Setup

The project needs Python 3.12 and uses [uv](https://github.com/astral-sh/uv). PyTorch and PyTorch Geometric are installed from the CUDA 13.0 wheel indexes set in `pyproject.toml`.

```bash
uv sync
```

## Usage

Run all commands from the repository root.

**1. Preprocess the data.** This reads `data/raw/` and `data/external/` and writes `data/interim/` and `data/processed/`:

```bash
python mir_gatboost/dataset.py
```

**2. Compute miRNA embeddings.** This step is optional because `artifacts/miRNA_embeddings.pt` is already included:

```bash
python -m mir_gatboost.features
```

**3. Train and evaluate HBoost-GAT with 3-fold stratified cross-validation:**

```bash
# 3 views (d = 128, 256, 512)
python mir_gatboost/modeling/HBoost-GAT.py --n-views 3 --n-components 512:256:128 --num-layers 2 

# 5 views (d = 64, 128, 256, 512, 1024)
python mir_gatboost/modeling/HBoost-GAT.py --n-views 5 --n-components 1024:512:256:128:64 --num-layers 2 
```

| Option | Default | Description |
|---|---|---|
| `--n-views`, `-nv` | 3 | Number of views K |
| `--n-components` | `512:256:128` | PCA dimensions, one per view, separated by colons |
| `--hidden-channels`, `-hc` | 64 | GAT hidden channels |
| `--num-layers`, `-l` | 1 | GAT layers (the paper uses 2) |
| `--n-iter`, `-i` | 10 | Boosting iterations T |
| `--epochs`, `-e` | 50 | Training epochs per boosting iteration |
| `--rebuild-index / --no-rebuild-index` | off | Force the Annoy neighbour indexes to be rebuilt |
| `--platform` | `MicroArray` | `MicroArray` or `NGS` |
| `--dataset-path` | `data/processed` | Processed dataset directory |
| `--artifacts-path` | `artifacts` | Directory with embeddings and indexes |
| `--output-path` | `results` | Base directory for scores |

**Outputs.** Each run is named `GATBoosting_F<d1>_..._I<T>_L<layers>_H<hidden>_SW`.
- `results/<run>/`:
  - `params.json`
  - `FOLD_<i>/scores_GAT_Boosting.csv` (per-class scores) and `FOLD_<i>/scoresAVG_GAT_Boosting.csv` (averaged scores)
  - `GLOBALscores.csv` and `GLOBALscoresAVG.csv` (mean ± std over folds)
- `models/<run>/FOLD_<i>/`: one checkpoint for each boosting iteration.
- `artifacts/indexes/<run>/`: Annoy indexes, reused across runs unless `--rebuild-index` is set.

**Exporting fold splits (optional).** This saves the per-fold PCA features and EXP/PD splits as pickles under `models/GATBoosting_<...>_PCA_TEST/`:

```bash
python -m mir_gatboost.utils.save_dataset --n-views 3 --n-components 512:256:128
```
